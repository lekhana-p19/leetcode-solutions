# Simple Line Editor - Help

## 1. Insert Line

Adds a new line at the specified line number.

Example:
1. Choose Insert Line
2. Enter line number: 2
3. Enter text: Hello World

## 2. Delete Line

Deletes a line from the document.

Example:
1. Choose Delete Line
2. Enter line number: 2

## 3. Display Document

Displays all current lines with their line numbers.

Example:
Choose Display Document

## 4. Exit

Closes the line editor.

Example:
Choose Exit
