## Problem: Reverse a String (Easy)
**Link:** https://leetcode.com

### Approach
Used a two-pointer technique initialized at the beginning and end of the character array. The characters are swapped in-place as the pointers move toward the middle index.

### Complexity
- Time: O(N)
- Space: O(1)

### Notes
Learned that swapping elements directly in-place allows us to achieve an optimal O(1) auxiliary space complexity without creating a secondary string copy.
